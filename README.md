# Signature assets

Curated, email-ready logo PNGs for the Veeva Email Signature Builder
(`~/veeva/pipelines/signature-builder/`). Hosted public so they can be
hotlinked from Gmail signatures — Gmail only keeps images served from a
public URL.

Each logo is a transparent PNG normalized to 120px tall (retina; display
smaller). Source art is Veeva's brand library; these are the standard
two-color horizontal marks. Falcon MLR uses its orange icon mark.

Raw URL pattern:
`https://raw.githubusercontent.com/aplmc-veeva/signature-assets/main/logos/<name>.png`
